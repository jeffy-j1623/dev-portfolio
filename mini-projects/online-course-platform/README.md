> # Online Course Platform – Course Detail Page (Mini Project)

## Project Description
This mini project is a **single-page HTML (HyperText Markup Language) application** that represents a real-world **online course detail page**, similar to platforms such as Udemy or Coursera.

The project focuses on building a **well-structured, semantic, accessible, and Search Engine Optimization (SEO)-friendly webpage using only HTML**

It is intended to strengthen and assess core HTML skills, including document structure, semantic elements, forms, accessibility, and metadata usage.

---

## Features
- Semantic HTML5 structure using:
  - `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Clear and accessible navigation layout
- Well-organized course overview section
- Instructor information with accessible image usage
- Course curriculum displayed using nested lists
- Accessible enrollment form with:
  - Proper `label` usage
  - `fieldset` and `legend` for grouping
  - Required form validation
- SEO-friendly metadata:
  - Page title
  - Meta description
  - Viewport configuration
- Screen reader–friendly document structure
- Clean, readable, and valid HTML code
